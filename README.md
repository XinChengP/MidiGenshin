# 原神原琴 MIDI 按键生成器

读取 `.mid` / `.midi` 乐曲，自动转换为原神 PC 端「风物之诗琴」可用的键盘按键时序，
支持预览、导出 txt 脚本、倒计时后台自动演奏（仅前台按键模拟）。

> 配套文档：`原琴MIDI按键生成器-需求文档.md`、`原琴MIDI按键生成器-界面布局描述.md`

## 功能

- **乐器切换**：风物之诗琴（21 键三行，C3–B5）/ 晚风圆号（14 键两行：`A S D F G H J` + `Q W E R T Y U`，C4–B5，无低音行）
- **文件加载**：拖入 `.mid` / `.midi` 或点击选择；多轨合并、自动变速（BPM）识别、打击乐通道默认忽略
- **音符映射**：内置两种乐器映射，整体移调 ±12、智能移调建议、黑键就近吸附（可改向上/丢弃）、超音域丢弃并统计、和弦合并为 `键1+键2`
- **预览面板**：时间 + 按键组合时序列表（和弦着色、吸附标注、时间跳转）
- **导出**：txt 时序脚本（UTF-8，`时间<TAB>键1+键2`，注释头含乐器/生成参数，可选分秒格式/按速度缩放）
- **自动演奏**：倒计时（0/3/5/10 秒，置顶浮窗）→ 前台模拟按键；演奏速度 50%–200%；
  **F8 全局急停**；暂停/继续；焦点保护（切回本工具自动暂停，切回游戏自动恢复）
- **明确不做**：音频播放、钢琴可视化、后台消息/内存注入、任何反检测设计

- Python 3.10+ 与 PySide6

## 启动

**推荐：双击 `启动原琴生成器.bat`**（已绑定本机 Python 3.10，无需配置）。

命令行方式（注意：本机 PATH 上的 `python` 是 msys64 的 3.14，**没有** PySide6，不要直接用）：

```bat
py -3.10 -m genshin_lyre [可选：mid 文件路径]
:: 或
C:\Users\ASUS\AppData\Local\Programs\Python\Python310\python.exe -m genshin_lyre
```

崩溃排查：pythonw 无控制台运行时，stdout/stderr 与启动错误会写入
`%TEMP%\genshin_lyre.log`；启动失败也会弹出错误对话框。

## 使用流程

1. 把 `.mid` 文件拖进窗口；
2. 在「参数」区调整移调 / 黑键策略 / 和弦容差 / 按键模式 / 演奏速度（改动即时重算）；
3. 点「智能移调建议」可自动选丢弃最少的移调档位；
4. 「导出 txt」留存按键时序脚本；
5. 点「▶ 播放」→ 倒计时期间切到原神窗口（打开风物之诗琴）→ 自动演奏；
   任意时刻 **F8** 急停，无按键残留。

## 快捷键

| 键 | 作用 |
|---|---|
| F8 | 全局急停 / 取消倒计时 |
| Esc | 取消倒计时 / 停止演奏 |
| Ctrl+O / Ctrl+S | 打开文件 / 导出（在工具窗口内） |

## 注意事项

- 演奏按键发往**当前前台窗口**：倒计时期间请切换到游戏窗口再等倒计时结束。
- 若游戏以**管理员身份**运行，本工具也需以管理员身份运行，否则系统（UIPI）会拦截模拟按键
  （工具检测到连续发送失败会自动中止并提示）。
- 自动化输入可能违反游戏用户协议，**仅供单机/离线练习，风险自负**；
  本工具不含任何规避检测的设计。

## 项目结构

```
genshin_lyre/          主包
  keys.py              21 键位表 / 音高映射
  midi_parser.py       SMF 解析（多轨合并、变速表、tick→秒）
  mapper.py            移调 / 黑键吸附 / 和弦合并 / 移调建议
  player.py            SendInput 演奏引擎（高精度计时、F8 急停、暂停、焦点保护）
  exporter.py          txt 时序脚本导出
  main_window.py       PySide6 主窗口 / 预览 / 统计 / 倒计时浮窗
  theme.py             浅色主题样式
examples/demo.mid      演示用 MIDI（含变速、黑键、超音域、打击乐轨）
tests/                 自动化测试与截图自检脚本
```
