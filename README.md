# 原神原琴 MIDI 按键生成器

读取 `.mid` / `.midi` 乐曲，自动转换为原神原琴可用的键盘按键时序（三排 / 两排两种键位），提供时序预览、txt 脚本导出、倒计时后前台自动演奏。

## 功能

- **乐器切换**：原琴·三排（21 键，低/中/高三行，C3–B5）/ 原琴·两排（14 键，中/高两行，C4–B5，无低音行）
- **文件加载**：拖入 `.mid` / `.midi` 或点击选择；多轨合并、自动变速（BPM）识别、打击乐通道默认忽略
- **音符映射**：按所选乐器映射，整体移调 ±12、智能移调建议、黑键就近吸附（可改向上/丢弃）、超音域丢弃并统计、和弦合并为 `键1+键2`
- **预览面板**：时间 + 按键组合时序列表（和弦着色、吸附标注、时间跳转）
- **导出**：txt 时序脚本（UTF-8，`时间<TAB>键1+键2`，注释头含乐器与生成参数，可选分秒格式/按速度缩放）
- **自动演奏**：倒计时（0/3/5/10 秒，置顶浮窗）→ 仅前台模拟按键；演奏速度 50%–200%；
  **F8 全局急停**；暂停/继续；焦点保护（演奏中切回本工具自动暂停，切回游戏自动恢复）
- **明确不做**：音频播放、钢琴可视化、后台消息/内存注入、任何反检测设计

## 运行环境

- Windows 10/11 x64
- Python 3.10+ 与 PySide6

```bat
:: 安装依赖（网络不畅时可用清华镜像 -i https://pypi.tuna.tsinghua.edu.cn/simple）
pip install PySide6
```

## 启动

**推荐：双击 `启动原琴生成器.bat`**（自动探测已安装的 Python 3.10+，无需配置）。

命令行方式（系统有多个 Python 时，请确认使用已安装 PySide6 的那个）：

```bat
py -3.10 -m genshin_lyre [可选：mid 文件路径]
```

崩溃排查：pythonw 无控制台运行时，标准输出与启动错误会写入 `%TEMP%\genshin_lyre.log`；启动失败也会弹出错误对话框。

## 使用流程

1. 把 `.mid` 文件拖进窗口；
2. 在「参数」区选择原琴键位（三排 / 两排），调整移调 / 黑键策略 / 和弦容差 / 按键模式 / 演奏速度（改动即时重算）；
3. 点「智能移调建议」可自动选丢弃最少的移调档位；
4. 「导出 txt」留存按键时序脚本；
5. 点「▶ 播放」→ 倒计时期间切到原神窗口（打开原琴）→ 自动演奏；
   演奏中切回本工具会自动暂停，切回游戏自动恢复；任意时刻 **F8** 急停，无按键残留。

## 快捷键

| 键 | 作用 |
|---|---|
| F8 | 全局急停 / 取消倒计时 |
| Esc | 取消倒计时 / 停止演奏 |
| Ctrl+O / Ctrl+S | 打开文件 / 导出（在工具窗口内） |

## 注意事项

- 演奏按键发往**当前前台窗口**：倒计时期间请切换到游戏窗口再等倒计时结束。
- 手动暂停（「⏸ 暂停」）后切窗口不会自动恢复，需点「▶ 继续」；焦点自动暂停则切回游戏即恢复。
- 若游戏以**管理员身份**运行，本工具也需以管理员身份运行，否则系统（UIPI）会拦截模拟按键
  （工具检测到连续发送失败会自动中止并提示）。
- 自动化输入可能违反游戏用户协议，**仅供单机/离线练习，风险自负**；
  本工具不含任何规避检测的设计。

## 项目结构

```
genshin_lyre/          主包
  keys.py              原琴键位表（三排 21 键 / 两排 14 键）与音高映射
  midi_parser.py       SMF 解析（多轨合并、变速表、tick→秒）
  mapper.py            移调 / 黑键吸附 / 和弦合并 / 移调建议
  player.py            SendInput 演奏引擎（高精度计时、F8 急停、暂停、焦点保护）
  exporter.py          txt 时序脚本导出
  main_window.py       PySide6 主窗口 / 预览 / 统计 / 倒计时浮窗
  theme.py             浅色主题样式
examples/demo.mid      演示用 MIDI（含变速、黑键、超音域、打击乐轨）
tests/                 自动化测试与截图自检脚本
```
